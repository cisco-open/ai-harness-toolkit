# Contributing to ai-harness-toolkit

We welcome contributions that improve the skills in this toolkit.

## Quick Start

1. **Create a GitHub Issue** -- Let us know what you want to add, change, or fix.
2. **Make your changes** -- Clone the repository, create a branch, and make your edits.
3. **Submit a PR** -- Code owners will be automatically assigned for review.

## Adding or Modifying Skills

Skills live in the `skills/` directory. Each skill has a `SKILL.md` file with YAML frontmatter that defines its metadata (name, description, compatibility, version).

When you add a new skill or modify an existing one, make sure the skill's `SKILL.md`
frontmatter stays accurate and complete.

## What We're Looking For

- **Content improvements** -- Better explanations, missing sections, clearer examples.
- **Error fixes** -- Typos, broken links, outdated information.
- **New skills** -- Task-specific agent skills with step-by-step instructions.

## Writing Style

Keep it practical and straightforward. Follow the repository's existing tone -- direct and helpful without being overly casual.

## Questions?

Create an [issue](https://github.com/cisco-open/ai-harness-toolkit/issues) in this repository.

## Security

Please do not report security issues in public issues or pull requests. Follow
the instructions in [SECURITY.md](SECURITY.md) to disclose vulnerabilities
responsibly.
