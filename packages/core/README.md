- `cisco-open/ai-harness-toolkit/skills/gh-pr-comment-resolution`

- `cisco-open/ai-harness-toolkit/skills/pr-follow-up`

```bash
apm install --allow-protocol-fallback cisco-open/ai-harness-toolkit/packages/core#core-v1.0.4
```
