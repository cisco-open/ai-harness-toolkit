# stack-spring-boot

Spring Boot package with `core`, Java implementation, and testing skills.

Included dependencies:

- `git: cisco-open/ai-harness-toolkit`, `path: packages/core`, `ref: core-v1.0.4`
- `github/awesome-copilot/skills/java-springboot`
- `github/awesome-copilot/skills/spring-boot-testing`
- `github/awesome-copilot/skills/java-junit`

Install with:

```bash
apm install --target opencode --allow-protocol-fallback cisco-open/ai-harness-toolkit/packages/stack-spring-boot#stack-spring-boot-v1.0.4
```
