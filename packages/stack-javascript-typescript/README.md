# stack-javascript-typescript

JavaScript and TypeScript base package for web composition on top of `core`.

Included dependencies:

- `git: cisco-open/ai-harness-toolkit`, `path: packages/core`, `ref: core-v1.0.4`
- `gohypergiant/agent-skills/skills/accelint-ts-best-practices`

Install with:

```bash
apm install --allow-protocol-fallback cisco-open/ai-harness-toolkit/packages/stack-javascript-typescript#stack-javascript-typescript-v1.0.4
```
