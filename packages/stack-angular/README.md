# stack-angular

Angular package with direct `core`, frontend guidance, JS/TS base, and Chrome DevTools MCP.

Direct install includes:

```text
stack-angular
  -> angular skill
  -> core
  -> web-design-guidelines
  -> stack-javascript-typescript
  -> chrome-devtools-mcp
```

Install with:

```bash
apm install --trust-transitive-mcp --allow-protocol-fallback cisco-open/ai-harness-toolkit/packages/stack-angular#stack-angular-v1.0.4
```
