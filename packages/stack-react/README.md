# stack-react

React package with direct `core`, frontend guidance, JS/TS base, and Chrome DevTools MCP.

Direct install includes:

```text
stack-react
  -> react skills
  -> core
  -> web-design-guidelines
  -> stack-javascript-typescript
  -> chrome-devtools-mcp
```

Install with:

```bash
apm install --trust-transitive-mcp --allow-protocol-fallback cisco-open/ai-harness-toolkit/packages/stack-react#stack-react-v1.0.4
```
